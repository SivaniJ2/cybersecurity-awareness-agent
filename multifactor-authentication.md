# Multifactor Authentication (MFA)

## What is MFA?

Multifactor authentication (MFA) is a security method that requires two or more different types of evidence to verify a user's identity before access is granted.

The factors generally include:

- **Something you know** — such as a password or PIN.
- **Something you have** — such as a phone, security key, or authentication device.
- **Something you are** — such as a fingerprint or other biometric characteristic.

## Why MFA is important

MFA adds another layer of protection to an account. If an attacker obtains a password, the additional authentication factor can make it more difficult for the attacker to access the account.

## Common examples

MFA may involve combinations such as:

- A password and a code generated by an authenticator app.
- A password and a security key.
- A password and a biometric verification method.

## Using MFA safely

- Enable MFA on important accounts whenever it is available.
- Prefer strong authentication methods recommended by your organization or service.
- Never share authentication codes with another person.
- Be cautious of unexpected MFA requests or approval notifications.
- If you receive an MFA request that you did not initiate, do not approve it and follow your organization's security procedures.
