# Cybersecurity Awareness Assistant

This repository contains public cybersecurity awareness resources used as a knowledge base for the **Cybersecurity Awareness Assistant**.

The assistant is designed to help users understand common cybersecurity risks and follow safer security practices.

## Topics Covered

The knowledge base currently includes:

- **Phishing** — recognizing and handling suspicious messages, links, and attachments.
- **Password Security** — creating, protecting, and managing strong passwords.
- **Multifactor Authentication (MFA)** — understanding MFA and using additional authentication factors safely.
- **Social Engineering** — recognizing manipulation and deception used by attackers.
- **Safe Browsing** — safer practices for websites, links, downloads, and online information.
- **Incident Reporting** — recognizing situations that should be reported and following appropriate reporting procedures.

## Sources

The cybersecurity guidance in this repository is based on publicly available resources from authoritative organizations, including:

- CISA — Cybersecurity and Infrastructure Security Agency
- NIST — National Institute of Standards and Technology

The individual topic files identify the relevant sources used for their content.

## Purpose

This repository is intended for **cybersecurity awareness and educational purposes**. It provides general guidance and should not replace an organization's specific security policies, procedures, or incident-response instructions.
